Chosen project: Student Portal. A teacher or class coordinator can add, search and list student records, view a Pass or Fail result and save the records.

Person stores the name. Student inherits from Person and keeps the ID, course and marks private. The vector in main stores the Student objects.

Sample marks and the other student names are demonstration data. A mark of 40 or more gives Pass in this example.

The file portal.csv uses ID,name,course,marks without a header. Commas are not allowed inside fields. Choose 4 to save before choosing 0 to exit.

The first run adds two records, searches for one, rejects a duplicate ID and invalid marks, handles an unknown ID and saves the valid records. The second run loads and lists those same records.

Result/Outcome
I learned how to combine classes, inheritance, a vector and exceptions in a small Student Portal. I also learned to save records in a CSV file and load them again when the program starts. Invalid marks, duplicate IDs and missing records are handled using clear error messages.
