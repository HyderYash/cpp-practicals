A stack follows last in, first out (LIFO).

The vector stores values of the template type T.

pop and peek return false when the stack is empty, so back() is never called on an empty vector.

peek reads the top value without removing it; pop removes the top value.

The fixed examples need no keyboard input.

Result/Outcome
I learned how to create one stack class for different data types using a template. I tested push, pop, peek and empty checks with integer, float and string values.
