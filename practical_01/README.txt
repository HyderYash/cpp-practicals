Uses int, double, bool and char variables, and the constant SUBJECTS.

Addition, multiplication and division perform the marks calculation.

Relational operators and logical AND validate marks and decide pass status.

The program prints the entered marks because redirected input does not echo.

Simple grading rule: A for at least 75% with all subjects passed; B for other passes; F if any mark is below 40.

Apple clang version 21.0.0 (clang-2100.4.1.1), arm64-apple-darwin27.2.0

Result/Outcome
I learned to use variables, basic data types and constants in C++. I used input, output and operators to calculate marks and check whether every subject was passed.
